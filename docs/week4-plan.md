## 评分与运行纪律

1. 问题和金标依据原始手册/源码，在第一次第四周执行前写好并冻结。不得依据本轮输出改题、放宽预期状态或删掉失败。发现金标缺陷时公开版本与原因，新旧运行分开。
2. 这是针对已知失败和类似改写的**非盲定向回归**，不是新的独立验收、生产样本或泛化证明。第三周成绩作为历史基线，不把两套分母或机械规则不同的通过率直接相减称为质量提升。
3. 自动检查负责状态、引用集合、工具边界、未确认不写入和事务不变量。AI逐题复核负责来源支持、事实归因、任务完成和危险断言，明确标为AI辅助评分；原定真人证据支持率仍未验证。
4. 草稿原话保留只保证没有后端自由扩写，不证明用户陈述真实，也不保证模型类别永远正确。有限敏感内容遮蔽不宣称完整脱敏；演示只输入模拟数据。
5. 时延、Token和未知费用按本轮真实结果记录，历史和检索对照额外调用单列。工具超时后恢复仍计超时；没有单价或账单时费用为未知，不能写零费用。
6. 模型行为仍有波动。回归失败要保存实际响应、轨迹和解释；若修复后重跑，另存运行并注明已查看案例，不反复挑选最好的一轮。

## 本周收尾标准

上述五项均有实现或明确边界、自动化检查和当前运行证据；12条真实配置图请求及其历史轮次执行完整并逐条复核（W403不调用模型）；新旧证据可区分；演示能展示修复机制、拒答、确认与真实限制。最终报告应逐项说明已达成、未达成和仍需真人验证的内容，不能仅以测试全绿宣布答案全部正确。
