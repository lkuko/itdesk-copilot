## 联调中发现并处理的问题

1. 服务商思考模式拒绝强制指定 `tool_choice`：能力检查改为标准 `auto`，并检查实际返回的工具名称和参数；不把普通文本回复当作通过。
2. 首次批量索引请求遇到超时：将离线批量缩为8条，离线单次预算60秒；在线仍为20秒、最多一次SDK重试，整轮90秒。重建失败保留旧索引。
3. 错误码只出现在首片段时，后半段的验证或转人工步骤可能遗漏：补充同文档相邻片段，仍保持独立引用ID；专门回归测试排除向量召回干扰。
4. 一次独立浏览器问答遇到模型超时，页面正确显示失败；再次请求成功并展示原文。该额外尝试不包含在18例统计内，说明在线延迟和可用性仍受服务商影响。

## 使用与边界

- 当前 [本地页面](http://127.0.0.1:8501) 与 [API文档](http://127.0.0.1:8000/docs) 已启动；再次启动请按根目录 README 的两个脚本运行。

- 资料为虚构示例，不用于真实故障处置，不接企业受限资料，不具备真实身份或文档ACL。
- `max_cosine_distance=0.50` 是开发默认值，未来应在开发集校准并在冻结集评估；尚未做纯向量与组合检索的消融实验。
